# CS Student Manager

컴퓨터공학 학생들을 위한 Android 앱입니다.

## 주요 기능

### 1. 바이트코딩 학습 도구
- 10진수를 2진수, 8진수, 16진수로 변환
- 비트 연산 실습 (AND, OR, XOR, NOT, Shift 연산)
- 실시간 연산 결과 확인

### 2. GitHub 관리
- GitHub 사용자 검색
- 사용자 정보 조회 (저장소 수, 팔로워, 팔로잉)
- 공개 저장소 목록 확인
- 저장소별 Stars, Forks, 사용 언어 정보

### 3. 컴공 용어사전
- 컴퓨터공학 관련 용어 검색 및 조회
- 카테고리별 분류 (알고리즘, 자료구조, 네트워크, 운영체제, 데이터베이스 등)
- 용어 추가 및 삭제 기능
- 실시간 검색 필터링

## 기술 스택

- **언어**: Kotlin
- **UI**: Material Design Components, ViewPager2, RecyclerView
- **네트워킹**: Retrofit2, OkHttp3
- **비동기 처리**: Kotlin Coroutines
- **아키텍처**: MVVM 패턴

## 빌드 요구사항

- Android Studio Arctic Fox 이상
- Minimum SDK: 24 (Android 7.0)
- Target SDK: 34 (Android 14)
- Gradle 8.2
- Kotlin 1.9.20

## 설치 방법

1. 저장소 클론
```bash
git clone https://github.com/your-username/cs-student-manager.git
```

2. Android Studio에서 프로젝트 열기

3. Gradle 동기화

4. 앱 실행
